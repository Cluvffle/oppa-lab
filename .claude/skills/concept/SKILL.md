# 서비스 구조

궁극 목표는 [[mission]] 참조. 이 문서는 챠밍이 실제로 무엇으로 구성되어 있는지 정의한다.

## 최상위 구조

```
챠밍 (Charming)
├─ 🏠 놀이터 홈             — 유입/락인/재방문 (결제 유도 X)
├─ 🚨 4대 할까말까            — 무료 무제한, 진입장벽 낮은 참여
├─ 📸 어필 피드             — 지속 브랜딩, 남성 유저의 성장 서사
├─ 👥 조언 받기 (매칭)      — 결제 진입점, 통화/실전 티어
├─ 💬 커뮤니티              — 자유 라운지, 학습, 졸업생 후기
└─ 📊 마이페이지            — 성장 대시보드, 라이프사이클 위젯
```

## 1. 🏠 놀이터 홈 — "매일 재밌게 놀러 오는 곳"

**철학**: 결제 유도 랜딩이 아니다. 치지직 홈처럼 **콘텐츠 구경만으로도 재미있는 놀이터**.

### 홈 구성 (스크롤 순서)

1. **지금 온라인** — 온라인 상태 여성 친구 카드 그리드 (라이브 뱃지 반짝임)
2. **실시간 할까말까 인기 질문** — 카톡/스타일/프로필/관계 할까말까에서 지금 뜨는 것들
3. **인기 어필 피드** — 남성 유저의 성장 숏츠/피드
4. **오늘의 팩폭 롤링** — 여성 친구가 남긴 명대사 자동 발췌
5. **이번 주 매력 남자** — 성장 스토리 하이라이트
6. **커뮤니티 실시간 인기글** — 자유게시판/졸업 후기 실시간
7. **결제 CTA는 각 카드 안에 자연스럽게** — 랜딩 자체가 유도 페이지가 아님

### 홈의 성공 지표
- 로그인 후 홈 체류 시간
- 스크롤 깊이
- 카드 클릭율

**하지 말 것**: 홈 상단에 "지금 결제하세요" 배너 X. 결제는 유저가 관심 콘텐츠 클릭 후 자연 유입.

## 2. 🚨 4대 할까말까 — "무료 무제한, 진입장벽 최저"

**철학**: 유저가 진짜 궁금한 스팟 질문에 여성이 즉시 답. 완전 무료 무제한. 유입 트래픽의 핵심 채널.

| 할까말까 | 남성이 올리는 것 | 여성이 남기는 것 | 담당 친구 |
|---|---|---|---|
| 📱 **카톡 할까말까** | 카톡 대화 스샷 (썸녀/소개팅) | 답장 예시 + 상황 분석 | 연습 파트너~연애 코치 |
| 👔 **스타일 할까말까** | 오늘 옷차림, 소개팅 코디 후보 | 스타일 피드백 (핏/컬러/조합) | 연습 파트너~연애 코치 |
| 📸 **프로필 할까말까** | 소개팅 앱 프사 후보들 | 어떤 게 나은지 + 이유 | 연습 파트너~연애 코치 |
| 💕 **관계 할까말까** | 여친/아내와의 갈등 상황 | 심리·관계 조언 | 연애 코치~관계 상담사 |

### 할까말까 공통 규칙
- 남성만 게시, 여성만 댓글 (여성 활성화 유도)
- 여성 댓글은 **템플릿 강제** (짧은 텍스트 어그로 방지, 상세는 [[emergency-rooms]] 참조)
- AI 조롱 필터 상시 가동
- 남성이 "도움됨" 클릭 → 여성에게 포인트 지급
- 게시자가 답변 채택 → 여성에게 추가 포인트

### 관계 할까말까 특수 룰
- **레드플래그 자동 감지**: 폭력/학대/우울증 → 전문 상담 안내로 자동 라우팅
- 심각도 판단 시 여성 친구도 "전문 상담 안내" 트리거 제공

## 3. 📸 어필 피드 — "나를 지속적으로 브랜딩하는 곳"

**철학**: 할까말까가 스팟 질문이면, 어필 피드는 **지속적 자기 브랜딩**. 인스타 피드와 숏츠 하이브리드.

- 남성만 게시, 여성만 피드백 댓글
- 카테고리: 스타일링 / 표정 / 헤어 / 목소리 / 카톡 스샷
- **성장 로그 기능**: 1주 전 vs 지금 나란히 보기, 피드백 반영 후 재게시 → 시각적 성장 서사
- 여성 얼굴 노출 강도 조절 (블러/음성만/스타일만) — 옵트인 방식

세부는 [[appeal-feed]] 참조.

## 4. 👥 조언 받기 (매칭) — "결제 진입점, 실제 통화/실전"

**철학**: 무료 할까말까에서 관계 맺은 여성 친구와 **집중적으로 1:1로 성장하는 유료 서비스**.

### 티어 구조 (라이프사이클별 노출 최적화)

| 티어 | 상품 | 소요 시간 | 가격 | 대상 단계 |
|---|---|---|---|---|
| 1 | 10분 음성 통화 + 리포트 | 15분 | 9,900원 | 입문기~ |
| 2 | 10분 영상 통화 + 리포트 | 20분 | 29,000원 | 성장기~ |
| 3 | 실전 오프라인 소개팅 + 리포트 | 약 2시간 | 149,000원 | 연애 도전기 |
| 관계 상담 | 20분 관계 상담 통화 | 20분 | 15,000원 | 연애 도전기~Grad+ |
| 부부 스크립트 케어 | 카톡 시나리오 3개 검토 | 비동기 | 9,900원 | Grad+ |

### 구독 상품

| 구독 | 구성 | 월 요금 | 대상 |
|---|---|---|---|
| **솔로탈출 4주 완정정복** | 음성 2 + 영상 2 + 실전 1 + 카톡 케어 | 199,000원 | 성장기~연애 도전기 |
| **관계 케어 라이트** | 할까말까 우선 답변 월 4회 + 상담 통화 월 1회 | 29,000원 | Grad+ |

세부 라이프사이클 매칭은 [[lifecycle]] 참조.

## 5. 💬 커뮤니티

**철학**: 완전 오픈 (누구나 열람 가능). 결제 유저 뱃지 노출로 자연 계층. 톤은 AI 필터 + 유저 신고.

### 게시판 카테고리 (3그룹 + 라이프사이클별 라운지)

**A. 유입/락인 (비회원도 열람)**
- 카톡 할까말까 인기 아카이브
- 첫인상 리포트 인증
- 오빠들의 성장일지

**B. 학습/자극**
- {{NUNA}}들의 오답노트 (여성 친구 큐레이션)
- 리얼 인터뷰
- 이번 주 매력 남자

**C. 커뮤니티/자유**
- 솔로 라운지 (입문기~연애 도전기)
- 고민상담소
- Q&A

**D. 라이프사이클 라운지 (신규)**
- 🎓 **졸업생 라운지** — 연애/결혼 성공 후기, Grad+ 유저 전용 자유 대화
- 💍 **부부 라운지** — 기혼 유저 전용 (여성 친구 관계 상담사 활동 채널)

상세는 [[community-rules]] 참조.

## 6. 📊 마이페이지 — 성장 대시보드

**철학**: 유저의 성장 서사가 시각화되는 곳. 라이프스테이지에 따라 위젯이 동적으로 바뀜.

### 공통 위젯
- **5개 성장 지표 레이더 차트** (첫인상/대화력/매너/외모관리/자신감)
- **여성 네트워크** (여사친 목록, 대화 횟수, 이번 달 대화 시간)
- **활동 타임라인** (통화, 리포트, 할까말까 활동)
- **획득한 배지**
- **다음 스텝 추천 카드** (AI 생성)

### 라이프스테이지별 위젯
- **입문기**: "오늘의 첫 통화 도전" 위젯
- **성장기**: "이번 주 지명한 누나" + "어필 피드 성장 로그"
- **연애 도전기**: "다가오는 소개팅 준비" + 3단계 CTA
- **Grad+**: "관계 히스토리" (여친/아내 갈등 로그, 조언 아카이브) + 관계 할까말까 CTA

세부는 [[growth-metrics]], [[lifecycle]] 참조.

## 유저 유형별 진입 흐름

### 남성 유저
```
비회원: 홈 놀이터 관람 → 할까말까/커뮤니티 열람 (읽기만)
        ↓
가입: 자유 닉네임, 기본 프로필, 성인 인증
        ↓
로그인 후: 할까말까 질문 → 여성 피드백 받음 → 여성 친구 카드 클릭
        ↓
자연 유입: "이 친구에게 더 자세히 조언받고 싶다" → 1단계 통화 결제
        ↓
반복 결제 → 지명 → 성장 → 라이프스테이지 진급
```

### 여성 유저
```
가입: 일반 회원 트랙 or 친구 트랙 선택
        ↓
일반 회원: 할까말까 댓글, 어필 피드백, 커뮤니티 활동 → 포인트 획득
        ↓
친구 승격 초대 (활동 실적 좋으면): 본인인증 + 스크리닝 통과
        ↓
친구: 유형 선택 (연습 파트너 / 연애 코치 / 관계 상담사)
        ↓
매칭 활동 + 커뮤니티 활동 → 통화 급여 + 포인트 리워드
```

세부는 [[panel-persona]], [[creator-economy]] 참조.

## 절대 원칙 요약

1. 홈은 결제 랜딩이 아니라 **놀이터**다
2. 할까말까는 **완전 무료 무제한**이다
3. 매칭 결제는 **관심 있는 친구 프로필에서 자연 유입**된다
4. 여성 유저의 활동에는 **실질적 보상**이 있어야 한다
5. Grad+ 유저를 **놓치지 않는다**
