# Creator Economy — 여성 리워드 시스템

궁극 목표는 [[mission]] (여성 친구의 지속가능성이 미션 완수의 축), 친구 유형은 [[panel-persona]] 참조.

## 대전제

- **여성 친구의 유지가 곧 서비스 지속가능성**이다. 매칭 대기 시간에도 접속할 이유가 있어야 함.
- **수익 채널 이중화**: 매칭 통화 급여 + 상시 참여 포인트
- **감정노동에 대한 실질 보상**: 관계 상담사는 프리미엄
- **성취감이 돈보다 강함**: "내가 도운 오빠들 성장 로그"

## 두 가지 수익 흐름

### 1. 통화 매칭 급여 (직접 정산)

| 티어 | 친구 수령액 | 유형 |
|---|---|---|
| 1단계 음성 (9,900원) | **4,000원** | 연습 파트너 / 연애 코치 |
| 2단계 영상 (29,000원) | **12,000원** | 연습 파트너 / 연애 코치 |
| 3단계 오프라인 (149,000원) | **60,000원** | 연애 코치 |
| 관계 상담 통화 (15,000원) | **9,000원** (60%) | 관계 상담사 |
| 부부 스크립트 케어 (9,900원) | **6,000원** (60%) | 관계 상담사 |

**관계 상담사는 급여율 60%로 상향** (일반 40%): 감정노동 프리미엄. 기혼/장기 연애 상담이 훨씬 무거운 활동.

### 2. 친구 포인트 (상시 활동)

| 활동 | 획득 포인트 |
|---|---|
| 할까말까 답변 게시 | +2P (게시만으로) |
| 할까말까 답변 도움됨 클릭 | +5~10P (룸별) |
| 할까말까 답변 채택 | +25~50P (룸별) |
| 어필 피드백 게시 | +2P |
| 어필 피드백 도움됨 | +5P |
| 커뮤니티 답변 도움됨 | +3P |
| 커뮤니티 답변 채택 | +15P |
| 월간 상위 3인 뱃지 | 보너스 +500P |
| 신규 친구 온보딩 시 이벤트 | 첫 30일 활동 +2배 |

### 포인트 → 실물 전환

**MVP 초기 (~6개월): 기프티콘 전환**
- 1,000P = 5,000원 상당 기프티콘 (스타벅스, GS25 등)
- 세무 부담 최소 (5만원 이하 소액은 사실상 문제 없음)
- 신청 → 24시간 이내 발송

**성장기 (6개월~): 현금 전환 옵션 오픈**
- 최소 전환 5,000P (25,000원)부터
- 은행 계좌 이체
- **원천징수(8.8%) 자동 처리 + 지급명세서 국세청 신고 인프라 필요**

## ⚠️ 세무 이슈 (매우 중요)

**법적 리스크 사항**. 서비스 확장 전 반드시 세무사 상담 필수.

### 원천징수 의무

여성 친구가 받는 돈은 대부분 **기타소득**으로 처리:

- 건당 5만원 초과 지급 시 원천징수(8.8%) 후 지급 의무
- 지급명세서 국세청 신고 의무 (월/분기별)
- 친구 개인의 종합소득세 신고 대상 판단 (연 300만원 초과 시)

### 사업소득 vs 기타소득 판단

- 지속적/반복적 활동으로 판단되면 **사업소득** 처리 (사업자 등록 필요할 수도)
- 챠밍처럼 정기적 친구 활동은 사업소득 판정될 여지 큼
- 친구가 사업자 미등록 시 챠밍이 원천징수(3.3%) 처리

### 부가세

- 친구가 사업자 → 세금계산서 발행
- 챠밍이 결제 대행자로서 부가세 신고 의무

### 실무 대응 로드맵

**Phase 1 (MVP, 매출 월 1억 미만)**
- 기프티콘 전환만 지원 (5만원 이하 소액)
- 친구 매칭 급여도 개인 계좌 지급 (사업자 미판정 리스크 감수)
- 세무사 자문받아 리스크 정도 정리 문서화

**Phase 2 (성장기, 매출 월 1억+)**
- 친구 트랙 이원화:
  - **일반 트랙**: 월 300만원 미만 활동 (기타소득 3.3% 원천징수)
  - **친구 사업자 트랙**: 사업자 등록 친구 (세금계산서 처리)
- 자동 원천징수 시스템 구축
- 정기 지급명세서 자동 제출

**Phase 3 (안정기)**
- 친구 세무 컨설팅 무료 제공
- 사업자 등록 지원 프로그램

## 친구 대시보드 구성

### 핵심 위젯

**1. 이번 달 수익**
```
━━━━━━━━━━━━━━━━━━━━
💰 이번 달 예상 수익
━━━━━━━━━━━━━━━━━━━━
매칭 급여: 148,000원 (12건)
포인트: 3,240P → 16,200원 상당
─────────────────
합계: 164,200원
```

**2. 활동 로그**
- 완료 통화 리스트
- 할까말까 답변 리스트
- 어필 피드백 리스트

**3. 내가 도운 오빠들 (성취감 위젯)** — 챠밍의 시그니처
```
━━━━━━━━━━━━━━━━━━━━
🌟 내가 도운 오빠들
━━━━━━━━━━━━━━━━━━━━
강남오빠 · 7회 대화 · 자신감 32 → 68
    "첫 소개팅 성공했어요, 감사해요"
연남오빠 · 4회 대화 · 첫인상 45 → 62
경기오빠 · 3회 대화 · 대화력 55 → 71
```
- 남성 유저가 남긴 감사 메시지 자동 표시
- 오빠가 졸업하면 **골드 편지지** 형태로 알림

**4. 온라인 상태 토글**
- 통화 매칭 가능 여부 실시간 전환
- 오늘의 예약 슬롯 관리

**5. 포인트 잔액 & 전환**
- 잔액
- 전환 옵션 (기프티콘 / 현금)
- 이번 달 원천징수 예상 금액 표시

## 활동 상한 (감정노동 보호)

- 하루 최대 통화 세션: **8건**
- 하루 최대 할까말까 답변: **20건**
- 관계 상담사 관계 할까말까 답변 상한: **10건** (감정 소모 큼)
- 야간 통화 (22시~) 요율 +20% (선택 참여)

## 친구 등급 & 승격

| 등급 | 조건 | 특전 |
|---|---|---|
| Bronze | 가입 완료 | 기본 활동 |
| Silver | 활동 30일 + 평점 4.0+ | 카탈로그 상단 노출, 요율 +5% |
| Gold | 활동 90일 + 평점 4.5+ + 30건 완료 | 요율 +10%, 야간 요율 자동 참여 |
| Diamond | 활동 180일 + Grad+ 오빠 도움 5명 | 요율 +15%, 챠밍 뱃지, 인터뷰 초대 |

## 매칭 알고리즘 (수요 배분)

**핵심**: 신입 친구도 매칭 기회 확보. 특정 친구에게 편중되지 않도록.

```python
def assign_call_priority(candidates: list[Creator]) -> list[Creator]:
    # 1. 유저 스테이지 매칭 (lifecycle 참조)
    # 2. 초심자 케어 태그 우선 (입문기 유저의 경우)
    # 3. 이번 주 매칭 수가 적은 친구 우선 (배분 공정성)
    # 4. 평점 가산
    # 5. 지명 요청은 최우선
    ...
```

## 신규 친구 온보딩 이벤트

- 가입 후 첫 30일: 모든 포인트 획득 2배
- 첫 통화 완료 시: 5,000원 상당 웰컴 기프트
- 지원 형태: 온보딩 튜토리얼 + 톤 가이드 실전 실습

## 이탈 방지 & 복귀 유도

**이탈 시그널**:
- 30일 미활동 → 재활성화 이메일 (특별 이벤트)
- 60일 미활동 → 상태 자동 `paused`
- 90일 미활동 → 친구 정지 (본인 요청 시 재활성화)

**복귀 시**:
- 복귀 첫 주 포인트 1.5배
- 이전 관계 히스토리 유지 (도운 오빠들 리스트 그대로 노출)

## 커뮤니티 & 인정 시스템

포인트/현금 외에도 친구에게 성취감을 주는 요소:

- **감사 편지**: 오빠들이 졸업하거나 성장 순간에 친구에게 편지 남기기
- **월간 표창**: 홈 놀이터 "이번 달 든든한 누나" 섹션
- **친구 스토리**: 리얼 인터뷰 게시판에 자기 활동 스토리 게시 가능
- **친구 커뮤니티**: 친구 전용 라운지 (경험 공유, 케이스 스터디)

## 지표 (플랫폼 관점)

- **친구 유지율**: 90일 활동 지속 친구 비율
- **친구당 평균 월 수익**: 활동 지속 동력 지표
- **매칭 배분 공정성**: 지니 계수 (특정 친구 편중 방지)
- **감정노동 지표**: 친구 자기 신고 스트레스 지수 (월 1회 짧은 설문)
