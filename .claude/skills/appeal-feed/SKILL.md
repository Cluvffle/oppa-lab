# Appeal Feed — 남성 유저의 지속 브랜딩 채널

전체 서비스 구조는 [[concept]], 할까말까와의 차이는 게시 형태(스팟 질문 vs 지속 브랜딩). 궁극 목표는 [[mission]] 참조.

## 대전제

- **남성만 게시 가능** (여성 유저는 피드백 댓글만)
- **자기 브랜딩 채널**: 할까말까가 "이거 어때요?"라면 어필 피드는 "이게 나예요"
- **성장 서사 시각화**: before/after 페어 기능 강조
- **얼굴 노출 강도 옵트인**: 블러 / 음성만 / 스타일만 / 얼굴 공개 옵션
- **여성 친구 피드백 톤 강제**: 할까말까와 동일한 템플릿

## 게시 카테고리

| 카테고리 | 코드 | 게시 형식 | 예시 |
|---|---|---|---|
| 스타일링 | `styling` | 옷차림 사진/영상 | 오늘의 데일리룩, 소개팅 코디 |
| 표정 | `expression` | 셀피 사진/짧은 영상 | 자연스러운 미소 연습, 사진 각도 |
| 헤어 | `hair` | 헤어스타일 사진 | 새로 자른 머리, 스타일 변화 |
| 목소리 | `voice` | 음성 클립 (30초 이내) | 자기소개 연습, 대화 톤 |
| 카톡 | `kakao` | 카톡 스크립트/스샷 | 실제 대화 스타일 브랜딩 |

## 게시 폼

**입력 항목**:
- 카테고리 (필수)
- 미디어 (필수, 최대 5개)
- 캡션 (필수, 200자 이내)
- 얼굴 노출 옵션 (사진의 경우):
  - `공개` / `블러` / `표정만 (눈 아래 블러)` / `실루엣만`
- 이전 게시글 페어링 (선택): 이전 스타일링 게시글 링크 → 성장 페어 자동 생성

## 성장 페어 기능

**핵심**: 같은 카테고리에 이전 게시글이 있으면 나란히 비교. 성장 서사의 시각화.

```
┌────────────────┬────────────────┐
│  1주 전 스타일  │  오늘 스타일   │
│                │                │
│  [이미지]      │  [이미지]      │
│                │                │
│  "이때 이런 지  │  "조언 반영해서 │
│   적 받았음"    │   이렇게 바꿈"  │
│                │                │
└────────────────┴────────────────┘

여성 친구 코멘트: "{{OPPA}} 진짜 많이 나아졌어요!"
```

**자동 페어 조건**: 같은 유저 + 같은 카테고리 + 30일 이내 이전 게시글 존재 시 게시 폼에서 페어링 옵션 노출.

## 피드 뷰

### 그리드 뷰 (기본)
- 인스타 스타일 정사각 그리드
- 카테고리 필터 (전체 / 스타일링 / 표정 / 헤어 / 목소리 / 카톡)
- 정렬: 인기순 / 최신순 / 팔로우 (선택적 팔로우 기능)

### 숏츠 뷰 (영상 카테고리)
- 세로 스크롤 풀스크린 (TikTok 스타일)
- 목소리 / 표정 / 헤어 영상에 최적화

### 상세 페이지
- 미디어 대형 노출
- 게시자 프로필 (닉네임 + 스테이지 뱃지)
- 캡션
- 성장 페어 (있으면)
- 여성 친구 피드백 댓글 리스트
- 좋아요 / 저장 / 공유

## 피드백 댓글 (여성 친구만)

**댓글 템플릿** (할까말까와 동일 구조):
```
1. 좋은 점 1가지 (필수)
   "이 스타일은 ~ 이 매력적이에요."
2. 개선 제안 1가지 (필수)
   "이 부분만 조정하면 훨씬 나아질 거예요."
3. 예시/구체안 (선택)
4. 응원 (선택)
```

### AI 톤 필터
- 할까말까와 동일한 임계값
- 성장 페어 게시글에는 특별히 응원 톤 우선 감지 (성장이 눈에 보일 때 격려하는 문화 유도)

## 남성 유저 액션

- **좋아요** ❤️: 좋은 어필에 지지
- **저장** 📌: 참고용으로 저장
- **공유** ↗️: 링크 or 커뮤니티에 재게시
- **팔로우** (선택 기능): 특정 유저의 성장 스토리 팔로우

**❌ 남성은 어필 피드에 댓글 불가** — 이건 여성 피드백 채널이라는 정체성 유지.

## 여성 친구 인센티브

할까말까와 유사한 포인트 시스템:

- 어필 피드백 댓글 게시: +2P
- 게시자 도움됨 클릭: +5P
- 여성 친구 활동 상위: 월간 "베스트 피드백러" 뱃지 + 보너스

세부는 [[creator-economy]] 참조.

## 여성 친구 매칭 로직

어필 피드는 친구에게 노출되는 우선순위가 있음:
- 유형 매칭 (스타일링 카테고리 → 연애 코치 우선)
- 온라인 친구 우선 노출
- 개인 관심 태그 기반 (스타일링 좋아하는 친구에게 스타일링 게시글 노출)

## 커뮤니티 · 대시보드 연동

### 홈 놀이터 노출
- **인기 어필 피드** 섹션: 좋아요 + 피드백 많은 게시글 상위 노출
- **성장 페어 하이라이트**: before/after 극적인 게시글 강조 (성장 서사 확산)

### 마이페이지 어필 성장 로그
- 자신의 어필 피드 게시 이력 카테고리별 정리
- 성장 페어가 자동으로 시계열 뷰로 시각화
- 받은 피드백 아카이브

### 이번 주 매력 남자 (커뮤니티)
- 어필 피드 성장 페어 중 극적 변화 게시글을 큐레이션
- 익명 옵션 (닉네임 노출 여부 선택) — 완전 익명 원칙 존중

## 얼굴 공개 관리

**옵션별 자동 처리**:
- `공개`: 원본 노출 (유저 선택 → 옵트인)
- `블러`: 얼굴 영역 자동 감지 후 가우시안 블러
- `표정만`: 눈 아래 반만 블러
- `실루엣만`: 얼굴/피부 톤 감지 후 실루엣 처리

**AI 얼굴 감지** 사용 (예: `face-api.js` 클라이언트 or 서버측 처리).

**주의**: 옵션 변경 시 즉시 재처리. 개인정보 관점에서 유저가 원본을 언제든 삭제 요청 가능.

## 얼굴 노출 없이도 어필하는 카테고리

- **목소리**: 음성 클립만 → 얼굴 노출 X
- **카톡**: 텍스트/스샷만 → 얼굴 노출 X
- **스타일링 (전신 뒷모습)**: 뒷모습만 → 얼굴 노출 X

이 카테고리로 진입장벽 낮은 어필 피드 문화 유도.

## 리스크 관리

### 어그로/스팸
- 하루 게시 상한: 3건
- 동일 미디어 재게시 감지 → 자동 반려
- 신고 3회 → 자동 검토

### 개인정보
- 위치 정보 자동 EXIF 제거
- 배경에 개인정보 노출 감지 (자동차 번호판 등) → 자동 블러 제안

### 조롱/공격 톤
- 할까말까와 동일한 AI 톤 필터
- 특히 이 유저가 얼굴 노출한 경우 톤 필터 임계값 더 엄격하게 (0.4 → 0.3)

## 지표 & 성공 판단

- **참여율**: 게시 1건당 평균 피드백 댓글 수
- **성장 페어율**: 전체 게시 중 성장 페어 비율 (많을수록 성장 서사 활성)
- **얼굴 공개 비율**: 스테이지 진급과 함께 증가 여부 (성장기 → 도전기 시 자연 증가 기대)
- **여성 친구 참여율**: 어필 피드에 댓글 남기는 친구 비율
