# Lifecycle — 4단계 라이프사이클

전체 철학은 [[mission]] 참조. 이 문서는 각 단계의 정의 · 진급 규칙 · UX 조정을 정의한다.

## 핵심 원칙

**"졸업은 이탈이 아니라 관계 진화다."** 사이다는 유저의 여자 대화 근육 없는 시절부터 결혼 이후까지 곁에 있는다. 각 단계는 완전히 다른 니즈를 가지며, UX/상품/톤이 그에 맞춰 조정된다.

## 4단계 정의

### 🌱 입문기 (Rookie)

**정의**: 여자와 대화하는 근육이 없거나 매우 약한 상태. 사이다 친구 0명 또는 없다시피 함.

**시그널**:
- 가입 후 30일 이내
- 통화 세션 0~2회
- 여성 네트워크(반복 대화한 패널) 0명
- 어필 피드 게시 0건
- 할까말까 활동 위주

**주요 니즈**:
- "누구에게든 여자한테 뭐 좀 물어보고 싶다"
- "여자 앞에서 무너지지 않는 감각을 처음 경험하고 싶다"
- 낮은 결제 부담

**추천 UX**:
- 홈 상단 위젯: "오늘의 첫 통화 도전"
- 할까말까 CTA 강조 (무료 진입 활동 유도)
- 1단계(9,900원) 반복 결제 노출
- 초기 패널 매칭에 **초심자 케어 태그** 붙은 친구 우선

**추천 친구 유형**: 연습 파트너 (20대 초중반, 초심자에게 부드러운)

---

### 🌿 성장기 (Growing)

**정의**: 특정 사이다 친구와 반복 대화하며 관계 형성 시작. 자신감이 붙기 시작하는 단계.

**시그널**:
- 가입 30일 이상
- 통화 세션 3~10회
- 여성 네트워크 1~3명 (같은 패널과 3회 이상 대화)
- 첫 지명 통화 발생
- 어필 피드 첫 게시 or 성장일지 첫 작성

**주요 니즈**:
- "이 친구랑 더 편해지고 싶다"
- "다양한 스타일의 여성과도 대화해보고 싶다"
- 영상 통화로 시각적 자신감 검증

**추천 UX**:
- 홈 상단: "이번 주 지명한 누나" + "어필 피드 성장 로그"
- 2단계(29,000원) 영상 통화 CTA
- 첫 구독 시도 프롬프트 ("솔로탈출 코스 어때요?")
- 어필 피드 카테고리 잠금 해제

**추천 친구 유형**: 연습 파트너 + 연애 코치 혼합

---

### 🌸 연애 도전기 (Challenger)

**정의**: 실제 소개팅 시도 or 관심 있는 여성에게 다가가는 단계.

**시그널**:
- 통화 세션 10회 이상
- 여성 네트워크 3명 이상
- 5개 지표 평균 65+
- 카톡 할까말까 사용 빈도 급증 (실전 카톡)
- 스타일 할까말까 소개팅 코디 질문 다수

**주요 니즈**:
- "실전 시뮬레이션을 해보고 싶다"
- "지금 진행 중인 썸의 다음 액션을 조언받고 싶다"
- 오프라인 실전 검증

**추천 UX**:
- 홈 상단: "다가오는 소개팅 준비" 위젯 (카톡 상황 요약, 스타일 체크리스트)
- 3단계(149,000원) 오프라인 실전 강력 CTA
- "솔로탈출 4주 완정정복 코스" 구독 강력 추천
- 카톡 할까말까 우선 답변 옵션 노출

**추천 친구 유형**: 연애 코치 (실전 경험 있음)

---

### 🌳 연애/기혼기 (Grad+)

**정의**: 여자친구가 있거나 결혼/기혼 상태. 사이다을 졸업한 게 아니라 다른 방식으로 계속 이용.

**시그널**:
- 유저가 프로필에서 스테이지를 **"연애 중"** 또는 **"기혼"** 으로 선택 (자기 신고)
- 또는 커뮤니티에 소개팅/연애 성공 후기 게시 → 자동 승격 제안
- 관계 할까말까 사용 시작

**주요 니즈**:
- "여친/아내랑 싸웠는데 어떻게 풀어야 할지 모르겠다"
- "아내가 요즘 왜 차가운지 여자 입장에서 알고 싶다"
- "기념일 이벤트 아이디어"
- 후배 오빠들에게 조언해주고 싶은 성취감

**추천 UX**:
- 홈 상단: "관계 히스토리" 위젯 + 관계 할까말까 CTA
- 관계 상담 통화(15,000원) + 관계 케어 라이트 구독(29,000원) 노출
- 부부 스크립트 케어 상품 노출
- **"사이다에서 시작한 오빠" 뱃지** 자동 부여 → 커뮤니티 답변 노출 시 강조
- 졸업생 라운지 / 부부 라운지 접근권

**추천 친구 유형**: 관계 상담사 (30대~, 연애/결혼 경험)

## 진급 조건 (자동)

라이프스테이지는 유저가 명시적으로 신고할 수도 있지만, 사이다이 활동 데이터로 자동 승격 제안도 함.

### 입문기 → 성장기 자동 제안

- 통화 세션 3회 완료 + 같은 패널과 2회 이상 대화
- 조건 충족 시: "오빠, 이제 성장기예요! 다음 스텝 확인해보세요" 알림 → 성장기 대시보드로 전환

### 성장기 → 연애 도전기 자동 제안

- 5개 지표 평균 65+ (30일 이상 유지)
- 카톡 할까말까 5회 이상 사용
- 어필 피드 3회 이상 게시
- 조건 충족 시: "오빠 이제 실전에 도전할 준비 됐어요" 알림 → 3단계 CTA 강조

### 연애 도전기 → Grad+ 자동 제안

- 커뮤니티에 소개팅/연애 성공 후기 게시 → 관리자 확인 후 승격 제안
- 또는 유저가 프로필에서 "연애 중" / "기혼" 스테이지 선택 시 즉시 승격
- 승격 시: **졸업 뱃지 지급 + 축하 애니메이션 + 후기 인터뷰 초대**

## 역진급 / 재활성화

- Grad+ 유저가 이별/이혼 후 다시 도전기로 복귀하고 싶다면 자기 신고로 스테이지 변경
- 이 경우 **재활성화 특전** 제공 (첫 통화 50% 할인 등)
- 사이다는 여러 번 실패해도 다시 시작할 수 있는 곳

## 스테이지별 톤 조정

같은 사이다 톤이지만 스테이지에 따라 미묘하게 조정:

- **입문기**: 격려 톤 강함. "천천히 해도 돼요", "처음이면 다 그래요"
- **성장기**: 도전 톤. "이번엔 한 걸음 더 나가볼까?"
- **연애 도전기**: 실전 코치 톤. "실전에서 이렇게 해봐요"
- **Grad+**: 성숙한 파트너 톤. "그 상황은 이런 감정일 수 있어요"

## 친구 매칭 우선순위

패널 카탈로그에서 유저 스테이지에 맞는 친구를 상단에 노출:

```typescript
function rankPanelsForUser(user: User, panels: Panel[]): Panel[] {
  const stageWeight = {
    rookie:     { practice_partner: 3, love_coach: 1, relationship_advisor: 0 },
    growing:    { practice_partner: 2, love_coach: 3, relationship_advisor: 1 },
    challenger: { practice_partner: 1, love_coach: 3, relationship_advisor: 1 },
    grad_plus:  { practice_partner: 0, love_coach: 1, relationship_advisor: 3 },
  }
  return panels.sort((a, b) =>
    stageWeight[user.stage][b.creatorType] - stageWeight[user.stage][a.creatorType]
  )
}
```

## 대시보드 위젯 동적 로딩

`user.stage` 값에 따라 마이페이지 위젯 세트가 다르게 로드됨.

```
if stage === 'rookie':
  widgets = [radar_chart, first_call_challenge, network_starter, community_intro]
elif stage === 'growing':
  widgets = [radar_chart, favorite_panels, appeal_feed_growth, subscription_hint]
elif stage === 'challenger':
  widgets = [radar_chart, upcoming_offline_prep, real_love_next_action, coach_recommendation]
elif stage === 'grad_plus':
  widgets = [relationship_history, grad_lounge_hot, relationship_emergency, mentor_activity]
```
