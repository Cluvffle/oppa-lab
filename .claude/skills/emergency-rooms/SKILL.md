# 할까말까 (Emergency Rooms) — 4대 방

전체 서비스 구조는 [[concept]], 사이다 친구 규칙은 [[panel-persona]] 참조.

## 네이밍 규칙 (중요)

- **UI 노출 라벨 (자연어)**: **할까말까** — "카톡 할까말까", "스타일 할까말까", "프사 할까말까", "관계 할까말까"
- **내부 코드 (변수·enum·경로·테이블)**: `emergency_rooms`, `emergency`, `kakao`, `style`, `profile`, `relationship` **유지**
- 스킬 문서·기능 문서에서는 문맥에 따라 두 이름을 병기 (첫 언급 시 "할까말까(emergency)" 로 매핑을 명확히)

**"응급실" 워딩은 UI에서 완전히 폐기.** "응급실"은 병원 뉘앙스로 사이다 놀이터 톤과 어긋난다. "할까말까"는 남성 유저의 실제 내적 갈등("이 답장 할까 말까")을 그대로 담아 친구가 함께 고민해주는 톤을 만든다.

## 대전제

- **완전 무료 무제한 게시** (모든 남성 유저)
- **여성만 댓글** (남성 유저는 좋아요/저장/도움됨만)
- **댓글 템플릿 강제** (조롱/공격 어그로 방지)
- **AI 톤 필터 상시 가동** (게시 전 스코어링)
- **친구에게 포인트 지급** (지속 참여 인센티브)

## 카톡 할까말까 (`kakao`)

**입력 폼**:
- 카톡 스샷 (필수, 최대 5장)
- 상대 정보 (선택): 관계 (썸녀/소개팅/여친/아내), 나이대
- 상황 요약 (필수, 200자 이내)
- 남기고 싶은 답장 초안 (선택)

**댓글 템플릿**:
```
1. 상황 진단 (필수, 1~2문장)
   "이 상황은 ~ 인 것 같아요."
2. 답장 예시 (필수, 3안 이하)
   "이렇게 해보면 어떨까요?"
3. 이유 (필수, 1~2문장)
   "여자 입장에서 이렇게 느껴서 그래요."
```

**포인트 지급**:
- 도움됨 클릭: +5P
- 게시자 채택: +30P

## 스타일 할까말까 (`style`)

**입력 폼**:
- 옷차림 사진 (필수, 전신 or 상하의)
- 상황 (필수, 예: 소개팅 / 오피스 / 데이트 / 평상시)
- 계절 (자동 추론 or 선택)

**댓글 템플릿**:
```
1. 좋은 점 (필수)
   "이 옷 자체는 ~ 이 매력적이에요."
2. 개선 제안 (필수)
   "이 부분만 조정하면 훨씬 나아질 거예요."
3. 대안 코디 (선택)
   "이런 조합은 어떤가요?"
```

**포인트 지급**:
- 도움됨: +5P
- 채택: +25P

## 프사 할까말까 (`profile`)

**입력 폼**:
- 프로필 사진 후보 (2~5장)
- 사용 플랫폼 (틴더/글램/골드/기타)
- 노리는 타입 (선택)

**댓글 템플릿**:
```
1. 어느 사진 추천 (필수, 번호 지정)
   "저는 2번이 제일 좋아요."
2. 이유 (필수)
   "표정이 자연스러워서 실물이 궁금해지거든요."
3. 개선 팁 (선택)
   "이 사진은 각도만 살짝 바꾸면 훨씬 나아질 것 같아요."
```

**포인트 지급**:
- 도움됨: +5P
- 채택: +25P

## 관계 할까말까 (`relationship`) — Grad+ 핵심

**입력 폼**:
- 상황 텍스트 (필수, 500자)
- 관계 유형 (필수): `dating` / `long_term` / `married` / `broke_up`
- 관계 기간
- 카톡 스샷 (선택)
- 원하는 조언 방향: `여자 마음 알고 싶어요` / `구체적 답장/행동 조언` / `관계 회복 방법`

**댓글 템플릿**:
```
1. 여자 입장 해석 (필수, 2~3문장)
   "아내분이 그렇게 반응하신 건 ~ 감정 때문일 수 있어요."
2. 구체적 조언 (필수)
   "다음엔 이렇게 해보시면 어떨까요."
3. 응원 (선택)
   "관계 회복하려는 오빠 마음이 대단해요."
```

**포인트 지급**:
- 도움됨: +10P (관계 할까말까는 답변 노력 큼)
- 채택: +50P

### 관계 할까말까 레드플래그 필터 (자동)

게시 시 다음 키워드/패턴 감지:

**폭력 (`violence`)**: 때렸다 / 맞았다 / 밀쳤다 / 폭행 / 물건 던짐
**학대 (`abuse`)**: 가스라이팅 / 통제 / 감금 / 금전 착취
**우울증 (`depression`)**: 죽고 싶다 / 자살 / 극단적 / 삶을 포기

**감지 시 자동 동작**:
1. 게시는 정상 진행되지만 상단에 **경고 배너** 표시
2. 친구에게 알림: "이 케이스는 전문 상담이 적절할 수 있어요"
3. 게시자에게 **전문 상담 안내 카드** 자동 노출:
   - 여성긴급전화 1366 (여성 대상)
   - 남성의 전화 (02-2653-1366)
   - 정신건강상담전화 1577-0199
   - 한국생명의전화 1588-9191
4. 친구에게도 "이 케이스는 넘겨주세요" 트리거 제공 (한 번 클릭으로 응답 대신 전문 안내 재게시)

- 채택된 댓글 상단 고정 + 골드 뱃지

## 남성 유저 액션

- **좋아요** (💚): 여성 답변에 감사 표시
- **저장** (📌): 마이페이지에 저장
- **도움됨** (필수 액션): 친구 포인트 지급 트리거
- **채택** (게시자만): 최고 답변 지정, 친구에게 대량 포인트

## 사이다 친구 액션

- 댓글 작성 (템플릿 강제)
- 자기 댓글 수정/삭제 (5분 이내)
- 신고 (게시글이 폭력/부적절한 경우)

## 포인트 & 리워드 흐름

할까말까는 친구의 상시 수입 채널.

세부 리워드 시스템은 [[creator-economy]] 참조.

**요약**:
- 도움됨: +5~10P
- 채택: +25~50P (룸별)
- 월간 할까말까 상위 3인: "베스트 스타일리스트" / "베스트 카톡 코치" 등 특별 뱃지 + 보너스 500P

## 게시 인기 지표

각 게시글의 지표:
- 답변 수 (`comments_count`)
- 도움됨 총합 (`helpful_total`)
- 채택 여부 (`is_adopted`)
- 노출 시간 대비 참여 (`engagement_rate`)

이 지표로 홈 놀이터의 "실시간 인기 할까말까 질문" 카드 노출 순서 결정.

## 커뮤니티 게시판과의 연결

- 채택된 답변이 있는 게시글은 **`kakao_archive` 커뮤니티 게시판에 자동 큐레이션** (익명화 처리)
- 유저는 자기 할까말까 게시글을 마이페이지에서 아카이빙 가능
- 사이다 친구는 할까말까 답변 실적을 친구 대시보드에서 확인

## 접근성 & UX

- 이미지 업로드: 카메라 촬영 / 앨범 선택 (모바일 우선)
- 카톡 스샷은 자동으로 개인정보 (이름/번호) 블러 처리 제안 (수동 확인)
- 모바일 스와이프로 할까말까 4개 탭 이동
- 답변 도착 시 실시간 알림 (푸시 or 인앱)
