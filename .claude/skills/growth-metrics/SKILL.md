# Growth Metrics — 성장 지표 & 여성 네트워크 & 졸업 시스템

궁극 목표는 [[mission]], 라이프사이클 진급 조건은 [[lifecycle]] 참조.

## 성장은 점수가 아니라 서사다

지표는 **도구**일 뿐. 진짜 자산은:
1. **여성 네트워크의 확장** (내가 어떤 여성들과 어떤 대화를 나눴는가)
2. **성장 서사** (6개월 전 나 vs 지금 나)
3. **관계의 성공** (실제 소개팅/연애/결혼)

이 세 가지를 대시보드가 동시에 보여줘야 함.

## 5개 성장 지표

| ID | 이름 | 티어 활성화 | AI 요소 | 친구 요소 |
|---|---|---|---|---|
| `first_impression` | 첫인상 | 1단계~ | 목소리 톤 | 첫 3분 인상, 인사 임팩트 |
| `conversation` | 대화력 | 1단계~ | 대화 점유율, 리액션 빈도 | 질문력, 유머 |
| `manner` | 매너 | 1단계~ | 무례 표현 감지 | 배려 발언, 존중 태도 |
| `appearance` | 외모관리 | 2단계~ (영상 이상) | — | 스타일, 헤어/피부, 자세 |
| `confidence` | 자신감 | 1단계~ | 목소리 크기, 말끝 흐림, 자기비하 빈도 | 표현 명확성 |

**중요**: `appearance`는 1단계 음성 통화에서는 활성화되지 않음 → 대시보드에 "2단계 영상 통화로 언락하세요" 문구 노출 (상위 티어 전환 명분).

## 점수 계산

각 지표는 0~100 정수. AI 요소 40% + 친구 요소 60%.

### 예시 (`conversation`):

```typescript
function calculateConversationScore(ai: AIAnalysis, creator: CreatorFeedback): number {
  const talkRatioScore = mapTalkRatio(ai.talk_ratio.user_pct)       // 0~100
  const reactionScore = mapReactions(ai.reactions_per_min)          // 0~100
  const questionScore = (creator.metric_sliders.conversation) * 10  // 슬라이더 0~10 → 0~100 근사
  const humorScore = 0  // (별도 슬라이더가 있다면)
  
  return Math.round(
    talkRatioScore * 0.2 +
    reactionScore * 0.2 +
    questionScore * 0.6
  )
}

function mapTalkRatio(userPct: number): number {
  if (userPct >= 40 && userPct <= 60) return 100
  if ((userPct >= 30 && userPct < 40) || (userPct > 60 && userPct <= 70)) return 70
  if ((userPct >= 20 && userPct < 30) || (userPct > 70 && userPct <= 80)) return 40
  return 20
}

function mapReactions(perMin: number): number {
  if (perMin >= 3) return 100
  if (perMin >= 2) return 70
  if (perMin >= 1) return 40
  return 10
}
```

### AI 요소 매핑 규칙 (상세)

**대화 점유율 (`talk_ratio`)**:
- 남성 40~60% → 100
- 30~40% or 60~70% → 70
- 20~30% or 70~80% → 40
- 그 외 → 20

**리액션 (`reactions_per_min`)** (예: "진짜?", "와~", "대박"):
- 3+/분 → 100
- 2/분 → 70
- 1/분 → 40
- 0 → 10

**음성 정체어 (`filler_words.count / duration_min`)** (예: "음...", "어...", "그니까..."):
- 2 이하/분 → 100
- 3~5/분 → 60
- 6+/분 → 20

**말끝 흐림 (감쇠 볼륨 감지)**:
- 문장 끝 볼륨 유지 → 자신감 만점
- 마지막 3음절 -6dB 이하 → 감점

**자기비하 표현 (`self_deprecation_count`)** (GPT 카운트: "저 원래 못생겨서", "제가 뭘 알겠어요"):
- 0회 → 100 / 1~2회 → 60 / 3+ → 20

**무례 표현 감지** (GPT 카운트):
- 0회 → 100 / 1회 → 40 / 2+ → 0 (매너 지표 즉시 큰 폭 감점)

## `raw_score` vs `display_score`

**핵심 심리**: 재결제 유도를 위해 점수가 **상승하는 경험**을 제공.

### 규칙

1. **첫 리포트는 의도적으로 낮게** — `display_score = min(raw, 65)`
2. **두 번째부터 자연 상승 가능**
3. **급상승 클리핑** — 한 번에 +20 이상 상승 방지
4. **급하락 완화** — 한 번에 -30 이상 하락 방지

### 코드

```typescript
function smoothDisplayScore(
  prev: number | null,
  raw: number,
  isFirst: boolean
): number {
  if (isFirst) return Math.min(raw, 65)
  if (prev === null) return raw
  const delta = raw - prev
  if (delta > 20) return prev + 20
  if (delta < -30) return prev - 15
  return raw
}
```

`raw_score`는 그대로 저장 (내부 분석용). `display_score`만 화면 노출.

## 여성 네트워크 확장 로그

**챠밍의 시그니처 대시보드 위젯**. 지표보다 더 강력한 심리 효과.

### 자동 집계 규칙

같은 `(user_id, creator_id)` 조합의 통화 세션이 발생하면 `FemaleNetworkEntry` 업데이트:

- **첫 통화**: 새 엔트리 생성, `first_talked_at`
- **매 통화**: `total_calls++`, `last_talked_at` 갱신
- **3회 이상**: `is_favorite = true` 자동 (여사친 인정)

### 대시보드 표시

```
🌸 나의 여성 네트워크
━━━━━━━━━━━━━━━━━━
✨ {{NUNA}} 3명 (3회 이상 대화, "여사친" 개념 — UI 라벨은 별칭 확정 후 조정)
   서연언니 (7번 · 3개월째)
   지원누나 (4번 · 1개월째)
   민지동생 (2번 · 2주째)

🌟 대화한 {{NUNA}}들 총 12명
📝 받은 조언 47개
💬 이번 달 여자와 대화한 시간: 3시간 24분
```

### 심리 효과의 의도

- **"이만큼 대화했다"는 사실 자체가 자신감**
- 실제 관계가 아니어도 **여자와 대화한 총 시간**이 대화 근육의 증거
- Grad+ 유저에게도 유의미 (아내 외 여성과 건강한 관계 유지 증거)

## 다음 스텝 추천 (AI 생성)

리포트 생성 마지막 단계에서 GPT가 다음 문장 생성.

### 프롬프트 규칙

- **입력**: 5개 지표 점수 + 최근 3회 평균 + 미획득 배지 + 유저 라이프사이클 스테이지
- **톤**: [[brand-charming]] 톤 규칙 준수 (친누나 톤)
- **금지**: 지적만 있는 문장, 결제 유도 CTA 직접 삽입 ("~하세요"는 OK, "결제하세요"는 X)

### 예시 프롬프트

```
당신은 챠밍의 다음 스텝 추천을 생성하는 코치입니다.
톤: 애정 어린 조언 톤 (친누나/여사친 톤과 동일 계열). 개별 친구 관점에서 1인칭 화자.

유저 정보:
- 스테이지: {stage}
- 이번 리포트 지표: {metric_scores}
- 최근 3회 평균: {avg_scores}
- 최저 지표: {weakest_metric}

이 유저에게 다음 스텝 한 문장 추천해주세요.
- 최저 지표를 개선할 방법
- 자연스럽게 관련 상품을 참조 (예: "영상 통화로 시선도 체크해볼까요?")
```

### 스테이지별 추천 예시

- **입문기 · 대화력 낮음**: "리액션이 조금만 늘어도 대화가 훨씬 살아나요. 다음엔 서연언니랑 한 번 더 연습해볼까요?"
- **성장기 · 외모관리 잠금**: "이제 영상 통화로 스타일도 봐드릴 수 있어요!"
- **연애 도전기 · 매너 낮음**: "매너 지표가 아쉬워요. 3단계 실전 소개팅으로 실제 매너를 검증받아보세요!"
- **Grad+ · 관계 할까말까 미사용**: "여친/아내와의 관계도 여자의 눈으로 봐줄게요."

## 배지 시스템

지표 성장과 별개 게이미피케이션.

### 배지 종류

| 배지 코드 | 이름 | 조건 |
|---|---|---|
| `first_step` | 첫 도전 | 1단계 첫 통화 완료 |
| `three_in_a_row` | 3회 연속 | 1주일 내 3회 통화 |
| `growth_king` | 성장왕 | 어떤 지표 +20 상승 |
| `all_perfect` | 오각편 | 5개 지표 모두 80+ |
| `dependable_oppa` | 든든오빠 | 커뮤니티 답변 베스트 3회 |
| `story_teller` | 스토리텔러 | 성장일지 게시 5회 |
| `dedication` | 진심의 오빠 | 3단계 (오프라인) 첫 도전 |
| `voice_master` | 목소리 마스터 | 자신감 지표 90+ |
| `reaction_king` | 리액션왕 | 대화력 지표 90+ |
| `network_5` | 여사친 5명 | 여성 네트워크 5명 이상 |
| `graduate` | 챠밍 졸업생 | Grad+ 승격 완료 |
| `oppa_mentor` | 오빠 멘토 | Grad+ 유저가 후배 답변 3회 채택 |
| `love_story` | 러브 스토리 | 실제 연애 성공 인증 |
| `wedding` | 웨딩벨 | 결혼 성공 인증 |

### 배지 노출 규칙

- **마이페이지**: 획득/미획득 모두 노출 (흑백 처리)
- **커뮤니티**: 자동 노출 X (완전 익명 원칙)
- **Grad+ 커뮤니티 답변**: `graduate` / `oppa_mentor` 배지만 예외로 노출 → 후배 오빠들의 신뢰

## 졸업 시스템

### 졸업 정의

**Before**: 서비스 이용 종료  
**After (챠밍)**: 라이프사이클 스테이지 진입 (`grad_plus`)

### 자동 승격 트리거

- 커뮤니티에 소개팅/연애 성공 후기 게시 → 관리자 확인 후 승격 제안
- 유저가 프로필에서 "연애 중" / "기혼" 선택 → 즉시 승격
- 관계 할까말까 3회 이상 사용 → 승격 제안 알림

### 승격 시 특전

- 🏆 **골드 졸업 뱃지** (프로필 대문 노출 옵션)
- 🎉 축하 애니메이션 + 카드 (마이페이지)
- 📖 **인터뷰 초대** (선택 참여) — 리얼 인터뷰 게시판에 성장 스토리 게시
- 💌 **감사 편지 작성 초대** — 도움 준 친구들에게 감사 편지
- 🎁 **관계 케어 라이트 구독 첫 달 50% 할인**
- 🌟 **오빠 멘토 활동 자격** — 커뮤니티에서 후배 답변 시 특별 뱃지

### 졸업 후 챠밍 활용

- 관계 할까말까 (여친/아내 갈등 상담)
- 관계 상담 통화 (관계 상담사와)
- 부부 라운지 (기혼 유저 커뮤니티)
- 오빠 멘토 활동 (후배 답변 · 인센티브)

**챠밍은 유저가 여러 라이프스테이지에서 계속 가치를 제공**하는 파트너.

## 대시보드 시각화

### 레이더 차트 (5개 지표)

recharts `RadarChart` 사용. 마지막 리포트 vs 이전 평균 비교.

### 지표 카드

```
┌───────────────────┐
│ 대화력 71 ↑12     │
│ ▓▓▓▓▓▓▓░░░       │
│ "리액션 훨씬       │
│  좋아졌어요!"     │
└───────────────────┘
```

### 시계열 라인

recharts `LineChart`. 최근 10회 리포트 지표별 점수. 색상은 친구별 구분 (같은 친구에게 반복 조언 받은 성장 곡선 시각화).

### 여성 네트워크 위젯

앞서 정의한 대로.

### 성장 서사 자동 요약 (AI)

지표 시계열이 극적으로 상승한 경우 감동 서사 자동 생성:

```
"6개월 전 자신감 32였던 오빠가 지금은 87이에요.
서연언니, 지원누나, 민지동생과 22번 대화하면서
꾸준히 노력한 결과예요."
```

이건 [[mission]]의 핵심: **성공에 챠밍이 함께 있었다는 서사를 각인**.

## 지표 프라이버시 원칙

- **본인만 열람**: 커뮤니티/피드에 자동 노출 절대 금지
- **인증 게시**: 유저가 스스로 스크린샷 공유는 자유 (성장일지 게시판)
- **여성 친구도 특정 유저 지표 열람 불가**: 자신이 도움 준 유저의 성장 곡선만 (친구 대시보드에서)
