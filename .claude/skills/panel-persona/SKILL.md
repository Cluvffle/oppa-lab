# Creator Persona — 여성 친구 규칙

궁극 목표는 [[mission]], 도메인은 [[domain-model]] 참조.

## 대전제

친구는 **"조언자·연습 파트너·관계 상담사"** 이지 **"서비스 대상"**이 아니다. 모든 UX·카피·시스템에서 이 위치를 지킨다.

## 3가지 친구 유형

라이프사이클 4단계에 맞춰 친구도 세분화. 자세한 매칭은 [[lifecycle]] 참조.

### 🌸 연습 파트너 (Practice Partner)

- **연령대**: 20대 초~중반 (`early_20s` ~ `late_20s`)
- **주 담당**: 입문기~성장기 남성 유저
- **캐릭터 무드**: 밝고, 부드럽고, 판단하지 않는 친구 톤
- **주요 활동**: 1단계 음성 통화, 할까말까 댓글, 어필 피드백
- **필요 자격**: 기본 본인인증 + 톤 스크리닝 통과
- **가격 티어**: 음성 4천원, 영상 12천원

**적합한 사람**: 
- 대학생, 사회초년생
- 커뮤니케이션에 관심 있는 사람
- 남성 초심자에게 참을성 있게 대할 수 있는 사람

### 💗 연애 코치 (Love Coach)

- **연령대**: 20대 후~30대 초 (`late_20s` ~ `early_30s`)
- **주 담당**: 성장기~연애 도전기 남성 유저
- **캐릭터 무드**: 실전 경험 있는 누나, 유쾌하면서 예리한 조언
- **주요 활동**: 영상 통화, 오프라인 실전 참여, 카톡 할까말까 심층 답변
- **필요 자격**: 기본 인증 + 연애 경험 인터뷰 + 심층 톤 스크리닝
- **가격 티어**: 영상 12천원, 오프라인 60천원

**적합한 사람**:
- 연애 경험 다수
- 소개팅 경험 다수
- 남자를 파악하는 눈이 있는 사람

### 💜 관계 상담사 (Relationship Advisor)

- **연령대**: 30대~ (`early_30s` ~ `late_30s_plus`)
- **주 담당**: 연애 도전기~Grad+ 남성 유저 (기혼/장기 연애 포함)
- **캐릭터 무드**: 성숙한 누나, 여성 시각에서 통찰 주는 상담사
- **주요 활동**: 관계 상담 통화, 부부 스크립트 케어, 관계 할까말까 댓글
- **필요 자격**: 기본 인증 + 장기 연애/기혼 경험 인증 + 관계 상담 톤 심층 스크리닝
- **가격 티어**: 관계 상담 통화 급여 상향 지급 (감정노동 프리미엄)

**적합한 사람**:
- 장기 연애 or 결혼 경험
- 심리/상담/HR 관련 경력 우대
- 남녀 관계의 뿌리 원인을 짚을 수 있는 사람

## 닉네임 규칙

**허용**:
- 한글 2~10자
- 호칭 접미 가능 (`언니`, `누나`, `동생`) — 관계 톤 예고
- 예: `서연`, `커피누나`, `민지동생`, `달리언니`

**금지**:
- 실명
- 성적 뉘앙스 (`섹시~`, `요염~`, `유혹~`)
- 브랜드/유명인 사칭
- 공격 뉘앙스 (`팩폭녀`, `저격수`, `현실직시녀`)
- 서비스 사칭 (`챠밍공식`, `관리자`, `운영자`)

## 캐릭터 이미지 (PixelLab)

### 캐릭터 스타일 카테고리

| 스타일 ID | 이름 | 매칭 유형 | 무드 | 시각 요소 |
|---|---|---|---|---|
| `bright-friend` | 밝은 친구 | 연습 파트너 | 발랄, 유머 | 컬러풀, 활짝 웃음 |
| `cute-younger` | 귀여운 동생 | 연습 파트너 | 순수, 애교 | 파스텔, 큰 눈 |
| `warm-elder` | 따뜻한 언니 | 연습 파트너 / 연애 코치 | 성숙, 다정 | 커피, 니트, 부드러운 미소 |
| `cool-elder` | 시크한 누나 | 연애 코치 | 세련, 도시적 | 블랙 셋업, 무표정, 커리어 우먼 |
| `quirky-artist` | 개성 아티스트 | 연애 코치 | 힙, 창의 | 헤어 컬러 포인트, 액세서리 |
| `mature-sister` | 성숙한 언니 | 관계 상담사 | 진중, 신뢰 | 단정, 은은한 표정 |
| `wise-noona` | 지혜로운 누나 | 관계 상담사 | 통찰, 공감 | 안경, 부드러운 미소 |

### 이미지 규격

- **비율**: 3:4 (카드용) + 1:1 (썸네일용) + 정사각 (프로필)
- **표정 세트**: 3종 필수 (neutral / smile / serious) — 리포트 톤에 맞춰 노출
- **스타일**: 부드러운 픽셀 아트 (16bit 감성)
- **배경**: 단색 or 파스텔 그라디언트
- **얼굴 노출 없음**: 실사 사진 절대 X, 얼굴은 픽셀 캐릭터로만

### PixelLab MCP 활용

`mcp__claude_ai_pixellab__create_character` 등으로 캐릭터 생성:
```
prompt: "{성격 태그} + {스타일 ID 무드} + soft pixel art, 16bit style, {배경 색상}"
```

## 피드백 톤 템플릿 (강제)

리포트 · 할까말까 댓글 · 어필 피드백 모두 **템플릿 강제**.

### 리포트용 (통화 후)

```
1. 장점 3개 (필수, 각 1~2문장)
   "○○ 오빠, 이런 점이 정말 좋았어요."
   
2. 아쉬운 점 2개 (필수, 각 1~2문장)
   "이 부분만 조금 신경 쓰면 훨씬 좋을 것 같아요."
   
3. 응원 한 마디 (필수)
   "다음엔 이렇게 해보면 어떨까요? 응원할게요!"
   
4. 인상 깊었던 순간 (선택)
```

### 할까말까 · 어필 피드백용 (짧은 형식)

```
1. 좋은 점 1가지 (필수)
2. 개선 제안 1가지 (필수)
3. 예시/구체안 (선택, 카톡 할까말까는 사실상 필수)
4. 응원 한 마디 (선택)
```

세부는 [[emergency-rooms]], [[appeal-feed]] 참조.

## 톤 예시 (좋은 예 · 나쁜 예)

### ✅ 좋은 예 (친누나 톤)
> "오빠 목소리가 되게 따뜻해서 듣기 편했어요. 그런데 제 이야기에 리액션이 조금 짧아서 아쉬웠어요.  
> '진짜?', '와 대박' 같은 리액션 조금만 더 해주면 대화가 훨씬 살아날 거예요.  
> 오빠 진짜 매력 있어요, 다음엔 더 잘할 수 있을 거예요!"

### ✅ 좋은 예 (관계 상담사 톤 — Grad+)
> "아내분이 그렇게 말씀하신 건 사실 서운함이 쌓여있어서 그런 것 같아요.  
> 여자 입장에서 '내 말 안 듣네' 라고 느끼면 감정이 훅 올라오거든요.  
> 다음엔 사과보다 먼저 '많이 서운했겠다' 하고 감정을 인정해주는 말을 해보세요."

### ❌ 나쁜 예 (조롱/팩폭)
> "리액션이 진짜 없네요. 그렇게 하면 여자들 다 도망가요. 목소리는 그나마 봐줄만 하네요."

## 온보딩 스크리닝

**오픈 플랫폼이지만 최소 필터** 필수:

### 공통 (모든 유형)
1. **본인 인증** (다날/NICE) — 성인 여성 확인
2. **자기소개 음성 30초** 제출 → 운영진 톤 검토
3. **피드백 예시 1건 작성** (샘플 통화 시나리오 주고 리포트 써보기)
4. **AI 톤 필터 자동 검사**: 조롱/공격성 스코어 < 임계값
5. **캐릭터 스타일 선택** → 활동 시작

### 유형별 추가
- **연애 코치**: 연애 경험 인터뷰 (온라인 폼)
- **관계 상담사**: 장기 연애/기혼 경험 인증 + 관계 상담 톤 스크리닝 (샘플 관계 할까말까 답변)

### 승격 경로 (일반 회원 → 친구)
일반 여성 회원이 커뮤니티에서 활동 실적 좋으면 → 친구 승격 초대. 이 경로가 오히려 톤 검증된 친구를 확보하는 최적 경로.

## 사후 관리

- **평점 4.0 미만 3회 연속** → 자동 활동 일시 정지 + 톤 재교육
- **혐오/공격 신고** → 즉시 검토, 확인 시 활동 정지
- **AI 톤 필터 임계 초과** → 자동 게시 보류 + 친구에게 재작성 요청
- **성능 상위 친구**: 프리미엄 뱃지 + 카탈로그 상단 노출

## 지명 시스템 (관계 형성 지원)

챠밍 미션의 핵심: 남성 유저가 **특정 여성 친구와 반복 대화하며 여사친 관계를 만드는 것**.

### 지명 규칙
- 남성이 특정 친구 다시 지명 가능
- **월 3~5회 상한**: 이후 다른 친구 자동 추천
- 상한 초과 시: "이제 새로운 관점도 필요해요!" 팝업 → 관계 다변화 유도
- 친구 측 신고 버튼 (특정 유저 거부 시 즉시 반영)

### 관계 히스토리 (양쪽 대시보드에 반영)

**남성 유저 대시보드에**:
```
🌸 나의 여성 네트워크
━━━━━━━━━━━━━━━━━━
✨ {{NUNA}} 3명 (여사친 개념 — UI 라벨은 별칭 확정 후 조정)
   서연언니 · 7회 대화 · 3개월째
   지원누나 · 4회 대화 · 1개월째
   민지동생 · 2회 대화 · 2주째
```

**친구 대시보드에**:
```
🌟 내가 도운 오빠들
━━━━━━━━━━━━━━━━━━
강남오빠 · 7회 대화 · 자신감 32 → 68
연남오빠 · 4회 대화 · 첫인상 45 → 62
```

이게 친구의 지속 동력이 됨. [[creator-economy]] 참조.

## 카탈로그 UX 힌트

**패널 카탈로그 페이지 필터**:
- 유형 (연습 파트너 / 연애 코치 / 관계 상담사)
- 성격 태그 (`돌직구`, `공감형`, `유머러스`, `차분함` 등)
- MBTI 그룹 (분석가 / 외교관 / 관리자 / 탐험가)
- 나이대 (20대 초 / 20대 후 / 30대)
- 온라인 상태 (지금 통화 가능)
- 유저 라이프사이클 자동 매칭 ON/OFF

**기본 정렬**: `유저 스테이지 매칭 우선 → 온라인 → 평점 순`.
